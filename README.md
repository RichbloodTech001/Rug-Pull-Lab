# RUG PULL LAB

Solana security research and trading laboratory for controlled Localnet and Devnet experiments.

## Phase 1 — Foundation

- Next.js + TypeScript application foundation
- Responsive research-console UI
- Solana Web3 dependency foundation
- Devnet-first safety boundary
- No private-key or secret storage
- Research navigation and experiment workspace

## Safety model

Rug Pull Lab is designed for security research, education, controlled simulations, and authorized Devnet/Localnet experiments. It does not implement live public-market rug execution, unauthorized asset extraction, or mechanisms intended to trap unsuspecting users.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Environment variables

Create `.env.local` locally when needed. Never commit credentials, API keys, seed phrases, private keys, or wallet JSON files.
